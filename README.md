## 📌 𝐀𝐁𝐎𝐔𝐓 𝐓𝐇𝐄 𝐁𝐎𝐓

EXRMAIL Telegram Bot is a powerful tool to manage Garena/Free Fire account email bindings. It allows you to change, cancel, unbind emails, convert tokens, generate JWT, and more - all through an easy-to-use Telegram interface.

---

## ✨ 𝐅𝐄𝐀𝐓𝐔𝐑𝐄𝐒

| Feature | Description |
|---------|-------------|
| 🔄 **Change Bind Email** | Change the email associated with your Free Fire account |
| ❌ **Cancel Bind Request** | Cancel pending email change requests |
| 🔓 **Unbind Email** | Remove email binding from account |
| 🔑 **EAT → Access Token** | Convert EAT token to Access Token |
| 📊 **Bind Info** | Check current email binding status |
| 🚫 **Revoke Token** | Invalidate access token |
| 🔐 **JWT Generator** | Generate JWT from access token |
| 👑 **Admin Panel** | Whitelist management for bot access |
